## 2. Logo

**Mark:** Concentric sonar arc/ring with a luminous center dot. Evokes both a sonar ping and the pupil of an ocean creature.

**Files:**
- `public/images/logo.png` — 1024×1024 PNG with alpha (~165KB). Used in Nav (32px) + Footer (40px).
- Generated by `gpt-image-2`, post-processed in PIL to extract cyan-on-transparent from black background.

**Usage:**
- Nav: 32×32px, hover rotates 30° via CSS
- Footer: 40×40px, static
- Spacing: 12px gap to wordmark
- Color: bioluminescent cyan `#4DEEEA` only — never recolor

**Wordmark:**
- zh: `沧渊` set in **LXGW WenKai** (calligraphic, contemplative)
- en: `OceanScale` set in **Geist 800** (heavy sans, SpaceX-style)
- Letter-spacing: -0.035em (en), -0.005em (zh)

## 3. Color Palette

CSS variables (defined in `src/styles/global.css` via `@theme`):

| Token | Value | Usage |
|---|---|---|
| `--color-abyss-0` | `#02050C` | Deepest dark, body background base |
| `--color-abyss-1` | `#0A1628` | Nav, footer, section backgrounds |
| `--color-abyss-2` | `#122438` | Card hover state |
| `--color-border-deep` | `#1F3047` | Borders, dividers |
| `--color-lumen` | `#4DEEEA` | **Primary accent** — bioluminescent cyan. CTAs, highlights, numbers |
| `--color-coral` | `#FF6B6B` | Rare emphasis only, not currently used |
| `--color-paper` | `#F7F4EE` | **Primary text** — cream, NOT pure white. Contemplative tone |
| `--color-paper-dim` | `#A8B5C2` | Secondary text |

**Rationale:**
- Background gradient `radial(cyan 6% at bottom) + linear(abyss-0 → abyss-1)` evokes depth + bioluminescence
- Cream text (`#F7F4EE`) instead of `#FFFFFF` reads as paper/document rather than UI — signals research/seriousness
- Cyan `#4DEEEA` chosen for biological feel (real sea-life luminescence) over typical tech-cyan

## 4. Typography

| Family | Source | Use |
|---|---|---|
| **Fraunces** | Google Fonts (variable, OPSZ + WONK axes) | Original en display (currently superseded by Geist) |
| **Geist** | Google Fonts (weights 400–900) | en body + en display (heavy) |
| **LXGW WenKai** (霞鹜文楷) | JSDelivr CDN | zh display + body (calligraphic literary) |
| **JetBrains Mono** | Google Fonts | Numeric, code, eyebrow labels, metric values |

**Sizes (responsive):**
- Hero H1: 5xl mobile / 7xl–[5.5rem] desktop
- Section H2: 4xl / 6xl
- Eyebrow label: `text-xs` (12px) uppercase, letter-spacing 0.3em
- Body: 1rem (16px), leading 1.6

**Rules:**
- **Never** use Inter, Roboto, Arial, system fonts (avoid AI-slop aesthetic)
- en display: Geist 800 + letter-spacing -0.035em + line-height 0.98 (SpaceX impact)
- zh display: LXGW WenKai 400 (calligraphic does its own work, no extra weight)
- Numbers always in JetBrains Mono (`.font-mono` class)

## 6. Motion

CSS-only, no animation library:

- **Hero load:** `fade-rise` keyframe — opacity 0→1 + translateY 1.5rem→0, staggered with delay-150/300/500/700
- **Sonar ping:** 3 concentric rings, scale 0.4→2.4 + opacity 0.55→0, 8s loop, 2.7s offset between rings
- **Button hover:** translateY(-2px) + glow box-shadow
- **Logo hover:** rotate 30deg over 300ms
- **Card hover:** subtle bg-color shift (`abyss-1` → `abyss-2`)
- **No JS animation libraries** (Framer Motion etc.) — performance budget

## 9. Voice & Copy

**Tone:** Mission-driven (SpaceX/Anthropic style), not feature-list.

**Principles:**
- Short sentences. Punch.
- Concrete numbers always (11,435 FPS, 90M env-steps/s, ¥10–100k/day).
- Active voice. "We're building" not "is being built."
- Customer-frame: speak to the labs/companies/defense, not about us.
- No jargon until after the hook.

## 10. Asset Generation Policy

**Image generation: ALWAYS use codex CLI (not direct OpenAI API).**

```bash
codex exec --skip-git-repo-check "Use your image_generation tool to create a [SIZE] image and save it to [PATH]. [PROMPT]"
```

Rationale: codex routes through the user's gpt-5.5 agent with image-generation enabled, billing through the codex account. Direct `https://api.openai.com/v1/images/generations` calls bypass this and use a separate OpenAI key.

**Video generation: fal.ai seedance 2.0 via REST.**

```bash
curl -X POST "https://queue.fal.run/bytedance/seedance-2.0/text-to-video" \
  -H "Authorization: Key $FAL_KEY" \
  -d '{"prompt":"...","resolution":"720p","duration":"5","aspect_ratio":"16:9","generate_audio":false}'
```

**Important:** Endpoint path is `bytedance/seedance-2.0/text-to-video` — **without** `fal-ai/` prefix. The queue accepts requests at any path but only the correct one routes to a real worker (others fail instantly with `inference_time < 0.1s` and `"Path not found"`).
