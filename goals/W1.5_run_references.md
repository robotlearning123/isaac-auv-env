## 6. Failure modes + recovery

| Failure | Recovery |
|---|---|
| **Isaac Sim 5.1 install > 4 h** (R1.2, R1.3) | Skip Isaac Sim path. Mark `runs?: FAILED, install_blocker`. Document attempt. Read-only source inspection of warplab/isaac-auv-env. |
| **RTX 5090 sm_120 incompatible with Isaac Sim 5.1** | Check NVIDIA docs; some Isaac Sim versions miss Blackwell support. Document. Fall back to Isaac Sim 6.0 Early Dev if available. |
| **bluerov2_gym install fails** (R1.1) | This is mandatory. Try smaller demo (just import); if even import fails, document blocker and escalate. |
| **MarineGym source files renamed since our earlier scan** | Re-grep for class names `UnderwaterVehicle`, `BlueROVHeavy`; use `git log` to find. |
| **Stonefish C++ build fails** (R1.5) | Optional. Mark FAILED. Read source via GitHub UI if needed. |
| **Disk space exhausted during Isaac Sim install** | Check `df -h /mnt/storage`; the cache is on /mnt/storage (436 GB free), OK; but `.venv/` per ref is on `/` (171 GB → may shrink). Cleanup if needed. |
| **GPU memory occupied (vLLM returns)** | Same protocol as 2026-05-15: tmux send-keys C-c to vllm-5090 session. |
| **Network throttling pip / git clone** | Use `--depth 1` clones; pip retry; document delays. |

**After W1.5**: we have:
- Verified MarineGym Fossen coefficients on file (R1.4) → no guessing in T2.2 added-mass
- Real Isaac Lab + rsl_rl PPO baseline numbers (R1.2) → calibrated v0.1 ship gate

- bluerov2_gym dynamics validated (R1.1) → cross-check our Fossen against theirs
- Stonefish hydrodynamic algorithms read (R1.5) → cite as algorithmic reference

W2's 12-30h estimate becomes much more defensible because **most of the unknowns become knowns** through W1.5's measurements.
