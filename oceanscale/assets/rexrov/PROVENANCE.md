# RexROV Assets Provenance

Source: UUV Simulator (https://github.com/uuvsimulator/uuv_simulator)
License: Apache-2.0
Paper: Manhaes et al., "UUV Simulator: A Gazebo-based package for underwater
       intervention and multi-robot simulation", OCEANS 2016

## Files
- `RexROV_no_props.dae` — hull visual mesh
- `RexROV_no_props.stl` — hull collision mesh
- `prop.dae` — propeller mesh
- `hydro_params.yaml` — Fossen 6-DOF hydrodynamic parameters (Ma, damping)
- `TAM.yaml` — 8-thruster allocation matrix
- `controllers/` — PID, nonlinear PID, sliding mode controller configs
