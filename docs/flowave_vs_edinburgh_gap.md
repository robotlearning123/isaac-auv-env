# OceanScale virtual FloWave vs real Edinburgh FloWave — gap analysis

Generated from 100 ccz verification agents (10 waves x ~10 facets). Each agent cited our code + `docs/flowave_edinburgh_reference.md` (source URLs inside). Opus aggregated + spot-checked.

**Verdict tally:** 19 match · 23 partial · 18 mismatch/gap · 40 unknown · 20 unparsed (of 100).

## Executive summary

A fleet of ccz agents (10 waves x 10 facets) compared OceanScale's virtual
FloWave against the real Edinburgh facility. Each agent cited our code and
`docs/flowave_edinburgh_reference.md` (the only sanctioned Edinburgh source).
Opus independently spot-checked the findings below against code + cited spec.

**CONFIRMED MATCHES (spec & linear wave physics):**
- **Geometry** — 168 flap paddles, 25 m working diameter (R=12.5). _(N=168, R=12.5 in paddle_array.py; ref: flowavett.co.uk)_
- **Depth** — 2.0 m SWL. _(water_usd.py _SWL=2.0; ref Wikipedia/flowavett)_
- **Current** — max 1.6 m/s, 28-unit equivalent. _(impeller_array.py max 1.6 m/s; ref flowavett)_
- **Dispersion** — Opus-recomputed L=0.765 m @ T=0.7 s, L=6.05 m @ T=2.0 s (intermediate-depth kh=2.08); matches agents. _(paddle_array.dispersion Newton-Raphson)_
- **Biésel flap H/S** — bottom-hinged form, H/S->2 as kh->inf (the bug fixed earlier this session). _(paddle_array.transfer_fn_HS)_

**REAL GAPS (ranked, evidence-cited):**
1. **W8 Active wave absorption [headline architecture gap].** Real FloWave paddles are *closed-loop force-feedback absorbing* (make AND absorb to kill reflections). Ours is *open-loop forward spectral synthesis*: `grep -ri absorb|reflect|feedback` over `facilities/flowave/*.py` finds only a marine-snow particle escape-reflect helper (coupling.py:345-347), **no wave absorption / no incoming-wave sensing**. Deepest fidelity difference.
2. **W3 Sub-design wave height [coverage gap].** Facility design point is **0.7 m @ 2 s**; our acceptance + render used **0.1 m** (~14%). No max-height / paddle-stroke cap in code — arbitrarily large H is silently accepted.
3. **W6 Raisable floor not modelled** — real tank raises its floor for depth control; ours is a fixed flat floor.
4. **W10 Unbounded operating envelope** — no coded stroke / velocity / max-H-vs-T limits; a real facility is bounded. (Edinburgh's envelope curve was **not publicly findable** — marked (not found), not invented.)
5. **W5 Spectra coverage** — JONSWAP confirmed; FloWave does arbitrary full spectra; our directional coverage is narrower.
6. **W4 Wave-current interaction** — ours superposes wave + current independently (architecturally correct per spec) but models **no refraction / Doppler coupling** between them.
7. **W9 Current uniform-core size** — our uniform region ~11 m diameter (r<=5.5) vs ~15 m test area; radial Gaussian decay is a modelling choice, not a measured profile.

**NOT FOUND in public Edinburgh spec** (neither matched nor faulted — flagged honestly): per-period wavelength table, max-H-vs-T operating curve, paddle stroke/velocity mechanical limits, exact paddle width & hinge depth, measured turbulence intensity. See `docs/flowave_edinburgh_reference.md`.

**Method honesty:** ours is deterministic spectral wavemaking (Biésel command + Airy superposition), not a causal CFD / absorbing-boundary solve. Matches are on specification & linear wave physics; gaps are on closed-loop control, absorption, and operating-envelope enforcement.
