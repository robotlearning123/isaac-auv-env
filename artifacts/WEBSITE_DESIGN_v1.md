## HERO

### 视频 (需要制作)

**镜头脚本:**
1. 开场: 暴风雨海面俯拍, 巨浪, 阴天, 压迫感 (1-2s)
2. 切入水下: 穿过水面进入深蓝, 光线从上方穿透 (1s)
3. 渐现仿真网格: 水下空间变为 GPU 仿真空间, 出现网格线/坐标系 (1s)
4. 拉远全景: 成千上万个水下机器人在网格化虚拟海洋中同时运动, 矩阵排列, 俯瞰视角 (2-3s)
5. 循环回到海面 (无缝 loop)

**风格:** 电影级, 暗色调, 青色 (#2dd4bf) 辅助光, 类似 NVIDIA GTC 发布会的仿真可视化
**格式:** MP4, 16:9, 1080p+, 10-15s 无缝循环
**备用 poster:** 第 4 步的静帧截图

### 布局

```
┌─────────────────────────────────────┐
│ [视频背景 100vh, 暗化叠加层]        │
│                                     │
│                                     │
│                                     │
│   面向水下机器人的                    │
│   海洋仿真基础设施                    │
│                                     │
│   一句话描述 (小字, muted color)      │
│                                     │
└─────────────────────────────────────┘
```

文字居中偏下, 给视频内容留空间。无按钮, 无装饰。

## 挑战

### 视频 (需要制作)

**镜头脚本:**
1. 船甲板实拍: 科考船/工程船, 人员在甲板操作 (2s)
2. 吊装 ROV: 起重机把机器人放入水中, 浪花飞溅 (2s)
3. 等待: 甲板人员看屏幕等数据, 天色变暗, 风浪变大 (2s)
4. 白板/显示器: 标注 "Weather canceled" / "Day 4 - Waiting" (1s)
5. 循环

**风格:** 纪录片质感, 去饱和, 强调等待和昂贵的感觉
**备选:** 用现有 hero-storm.mp4 + challenge-vessel.mp4 剪辑

## 平台

### 可视化 (需要制作)

**核心图: 架构流程图**
```
                    OceanScale
┌─────────────────────────────────────┐
│                                     │
│  物理引擎 ──→ 传感器 ──→ 环境 ──→ 策略 │
│  (GPU)       (DVL/IMU)   (×1000s) (RL) │
│                                     │
└─────────────────────────────────────┘
   Newton+Warp    仿真传感器   Gymnasium   PPO/SAC
```

**风格:** 深色背景, 线性连接, 节点发光, 类似芯片架构图
**格式:** SVG 或 CSS 实现 (不用图片, 保持清晰)

### 每个 card 的配图 (需要制作)

| Card | 配图描述 |
|------|---------|
| 物理引擎 | GPU 上多体碰撞/流体的仿真截图, 粒子/网格可视化 |
| 规模 | 鸟瞰矩阵: 8×8 或更大的并行环境网格, 每格一个机器人在不同状态 |
| 传感器 | 传感器数据可视化: DVL 速度矢量 + IMU 姿态 + 声纳扇形图, 叠加在机器人周围 |
| 接口 | 代码截图: 10 行 Python 代码创建环境并训练, 干净的 IDE 风格 |

### 图片 (已有)

- `platform-desk.webp` — 双屏 IDE + 3D ROV 渲染 (可作为 section 背景)
- `hero-impact-alt.webp` — 水下 ROV + 声纳网格 (可用于传感器 card)

## 基准

### 可视化 (需要制作)

**核心图: 三维竞争象限**

不是简单的速度对比条形图。三个维度:

```
            保真度 ↑
              │
  Stonefish ● │          ● OceanScale
  HoloOcean   │            (高保真+GPU+RL原生)
              │
              │    ● MarineGym
              │      (GPU但简化)
              │
  ────────────┼──────────────→ 速度
              │
              生态就绪度 (圆点大小)
```

**风格:** 暗色背景, 网格线, OceanScale 用品牌色 (#2dd4bf) 高亮, 其他用灰色
**格式:** SVG 或 Canvas, 可交互 hover 显示详情

**备选简化版:** 对比表 + 表上方嵌入已有的 `bench-landscape.webp` (白板竞争象限照片)

### 视频 (merge 原 Demo section)

基准表下方嵌入训练可视化视频:
- 并行训练全景 (俯瞰)
- 训练曲线实时叠加 (reward/loss)
- 不是单个 ROV 悬停, 是大量机器人同时学习不同任务

### 图片 (已有)

- `bench-landscape.webp` — 白板竞争象限 (Underwater Sim Landscape)
- `hero-bg.webp` — 海底地形等高线 (可作为 section 背景纹理)
